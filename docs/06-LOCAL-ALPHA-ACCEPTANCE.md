# Codex Monitor 本地 Alpha 验收记录

日期：2026-08-12  
结论：本地 Alpha 的设计、实现、只读真实集成、原生界面和可运行应用包已经完成。会产生模型用量的真实任务闭环、Developer ID 签名/公证、长稳和外部 Beta 不在本次无额外授权验收范围内。

## 1. 已交付能力

- SwiftUI macOS 14+ 主窗口与 360 pt 菜单栏面板。
- 项目侧栏、紧凑职员卡、自适应网格、状态指标、搜索与筛选。
- 授权和补充信息使用红色“举手”；完成未阅使用绿色“举手”。
- 交办任务、历史档案显式接管、一次允许/拒绝/取消、补充信息和中断。
- 应用托管 `codex app-server --listen stdio://`，无网络 listener、无 Hook。
- 其他本机 Codex 会话通过 rollout 生命周期信封只读观察，卡片标记 `OBSERVED`；授权仍回原客户端处理。
- 软件启动后新增的 Codex Desktop、VS Code、CLI 会话由 App Server State DB 最近页自动发现，正常约 5 秒同步，无需手动刷新。
- 后台发现、手动刷新和唤醒校准共用单飞控制；增量页只新增未知会话，不删除或覆盖现有卡片。
- JSONL 拆包、类型化 RPC 白名单、12 秒超时、连接代次和旧请求失效。
- App Server 退出退避重连、手动幂等重连、睡眠唤醒校准与退出保护。
- 本地通知、完成通知 10 秒聚合、通知点击定位任务。
- 隐私最小缓存、诊断脱敏、缓存一键清理和未来版本只读退化。
- 0.142.2 与 0.144.1 版本化协议 schema。

## 3. 原生界面验收

使用 macOS 原生辅助功能树与截图检查了：

- 1180×760 推荐窗口：连接状态、指标带、项目轨道、筛选、搜索和空状态清晰。

- 设置与诊断：Codex 版本、连接、隐私、通知、诊断和本地数据完整。
- 手动重连：从 LIVE 进入 SYNCING 后恢复 LIVE，不再出现重复 Server 错误。

- 交办任务 sheet：项目、目标、模型、安全说明和禁用提交态正确；验收未提交真实任务。
